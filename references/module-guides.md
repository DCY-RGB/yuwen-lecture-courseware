# 各板块讲评规范

这份规范回答的是：**什么样的内容放进课件，老师上课才真的省力、学生才真的听得懂**。每个板块先写「它要解决什么」，再写怎么写。

目录：现代文 · 文言文 · 古诗 · 默写 · 语言文字运用 · 写作 · 通用要求

---

## 现代文阅读

**目标**：让学生看见「答案是怎么从原文长出来的」，而不是只看到一个答案。

**材料页**
- `reading_tip`：一句话读法。文学类先抓情感线；论述类先抓论点和论证结构；实用类先抓信息来源与对象。
- `structure` + `thread`：用 3–5 步写清文章脉络。情感线用箭头串起来（嫌 → 悟 → 念）。
- `approach`（左栏「做题思路」）：写这一类文章的通用方法，不是某一道题的答案。

**文学类主观题统一用「三问成段」**：
1. 写了什么（内容）
2. 怎么写的（手法）
3. 为什么写（情感主旨）

`approach` 数组就按这三问分条写，学生跟着三条走，答案就成段了。

**选择题**：每个选项都写 `analysis` 和 `basis`。错误选项要点名错误类型（曲解原因、无中生有、以偏概全、偷换概念、虚实混淆、张冠李戴），长期使用，学生会形成「找错因」的习惯。

**`evidence`**：每道题至少一条，指向原文**最能支撑答案**的句子。如果答案依据分散在两处，写两条。

**常见误区（`pitfalls`）**：写学生**真实会犯**的错。例如「把散文当议论文答」「手法题只写手法名不写效果」。不写「审题不仔细」这类空话。

## 文言文阅读

**目标**：原文和解析在同一屏，词句不用翻资料。

**材料页**
- 每段 `text` + `trans`（译文）。译文要和原文**一段对一段**，不要合并或拆分，否则对照页会错位。
- `glosses`：给**考点词**加释义——实词多义、一词多义、通假、词类活用、特殊句式里的关键词。不必给每个字加，加太多就等于没加。
  - `char`：单字词；`word`：双音词或固定短语
  - `gloss` 写成「于：比」「知：通『智』，智慧」这种能一眼看懂的格式
  - **不确定的词不写**
- 多材料（材料一、材料二）：分成两个 passage，`label` 写「材料一」。

**断句题**：`approach` 用「四步法」：
1. 找对称（结构相同的句子，断点相同）
2. 找虚词（发语词、句末语气词，常出现在句首或句末）
3. 找名词、人名、官职（常作主语或宾语，前后断开）
4. 通读验证（断完读一遍，意思通不通）

**翻译题**：`points` 按得分点写，每条标分值，分三类：关键实词、特殊句式、整句通顺。`pitfalls` 写常见丢分点（漏译虚词、不落实通假字、该意译处直译）。

**词义/内容概括题**：每个选项回到原句；错项要说清错在哪里（时间错、人物错、因果倒置）。

## 古代诗歌鉴赏

**目标**：学生手边有译文，讲评时顺口就讲。

**材料页**
- `kind: "poem"`，`numbered: false`。
- 每个 `paragraphs` 元素是**一联**（或一句）。`label` 写「首联」「颔联」。`trans` 写这一联的白话译文，一句对一句，**不要写成赏析**。
- `notes`：难字、典故、古今异义，按 ①②③ 编号显示。
- `structure`：按联写「写景 / 抒情 / 叙事」的功能；`thread` 写全诗情感一句话。

**题目**
- 选项 `basis` 写「对应首联」「对应颈联」，这样鉴赏题的出处句一目了然。
- 鉴赏题的评判标准：**手法 + 诗句 + 效果**，三项齐全。`points` 照此写。
- 情感判断必须与全诗基调一致。诗歌的情感类选项错误，大多是「基调误读」。`pitfalls` 里写明。

**注意**：古诗的鉴赏结论（尤其是颔联、尾联的解读）常有不同说法。官方答案优先；没有官方答案时，写主流解读，并保持 `reviewed: false`。

## 名篇名句默写

**目标**：一问一屏，写完再揭晓，错字当场红给学生看。

- 一道题的每个小问放在 `subs` 里；每个空放在 `blanks` 里。
- **`answer` 只写应填的内容**，不要带题干里已有的字。
- **`hot` 易错字**：只选真正高频出错的字——形近字、同音字、生僻字。每空 0–2 个，不要整句标红，标得太多就失去提示作用。
  - 想提示具体怎么错的，用 `{ "c": "蜉", "wrong": "浮" }`。确认确实是常见错法再写。
- `alt`：通假字、异体字、版本不同（如不同选本的用字）都写进去，避免把对的判成错。
- 每个小问的 `stem` 保留原题的情景和空格，不要改写。

## 语言文字运用

**目标**：把每个选项为什么对错讲透。

- **成语/词语辨析**：每个选项的 `analysis` 先写词语本义，再写错在哪（望文生义 / 感情色彩不合 / 对象不当 / 语义重复）。
- **病句**：点名病因（成分残缺、搭配不当、语序不当、不合逻辑、表意不明、句式杂糅）并说明如何改。
- **标点、衔接、仿写**：主观题用 `points` 分条写得分点。
- 标 `tag: "选讲"` 或 `"重点"`，帮老师在时间紧时取舍。

## 写作

**目标**：备一节作文讲评课，不用另做 PPT。

写作的六个标签页对应作文讲评的六个环节，按需写，不必全写：

1. **审题立意**（`analysis`）：先给材料做一句话解读；`angles` 列 3 个左右角度并标明层次（稳妥 / 较深 / 冒险）；`traps` 写偏题风险。
2. **结构框架**（`structure`）：开头—主体—结尾，各部分写要做什么、大致字数。
3. **素材库**（`materials`）：每条素材写「用于论证什么」。**只写有把握的真实素材**，不要为了凑数编人物事迹。
4. **开头结尾**（`openings` / `endings`）：每种写法起个名（亮观点式、设问式、回扣式），附一个示例。
5. **范文对照**（`model`）：段落旁写批注（`comment`）——这段好在哪、哪里还可以讨论。批注要有讲评价值：除了夸，也留一两个可以追问的点（例如论证因果是否成立）。范文如果只是节选，设 `excerpt: true`。
6. **评分量表**（`rubric`）：按本地考试的评分标准写（立意 / 结构 / 语言 / 卷面，或基础等级 / 发展等级）。

没有官方范文时，**明确标注「示例」**，不要冒充官方满分作文。

## 通用要求

- **解析只写必要的**：每题解析三五句足够；讲评课要的是「课件上有，老师再展开」，不是把答案写成论文。
- **做题思路写成步骤**：动词开头（「圈出」「回到原文」「对照」），每步可执行。避免「认真审题」这种无法执行的话。
- **常见误区要具体**：写错因，不写态度。
- **难度和标签**：`difficulty` 只写有把握的；`tag` 的「选讲 / 重点」帮老师决定哪题多讲、哪题一句带过——这是整个课件最实用的取舍线索，建议每个板块至少标 1–2 题。
- **用词统一**：全卷同一个概念用同一个称呼（「依据句」「得分点」），学生不会困惑。
